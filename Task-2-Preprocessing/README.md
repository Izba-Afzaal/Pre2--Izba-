# Task 2 — Data Preprocessing and Visualization

## Objective
Clean and prepare the collected news article dataset for analysis and visualization.

## Project Overview
This task focuses on preprocessing a large news dataset, handling missing or duplicate records, standardizing data, and preparing the cleaned data for analysis.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Streamlit
- PostgreSQL

## Project Files
- `preprocess-news.py` — data cleaning and preprocessing code
- `100k_news_cleaned.csv` — sample of the cleaned dataset
- `app.py` — interactive news dashboard
- `charts/` — generated data visualizations
- `screenshots/` — dashboard screenshots

## Output
A cleaned news dataset and interactive visualizations for exploring news article data.

## Note
The full dataset contains approximately 100,000 records. A representative sample may be shared in this repository instead of the complete dataset.
