# Task 3: News Dataset Data Validation And quality assesment 

## Project Overview

This project focuses on performing data validation on a news articles dataset to ensure data accuracy, consistency, completeness, and reliability.

The main purpose of this task is to identify data quality issues, validate dataset fields, detect duplicate records, and assess the overall quality of the collected news data.

## Objectives

- Validate the structure and schema of the dataset.
- Identify missing and null values.
- Detect duplicate news records.
- Validate URLs and domain information.
- Check data consistency and correctness.
- Identify invalid or problematic records.
- Assess field completeness and source quality.
- Generate validation reports for further analysis.

## Data Validation Techniques

The following validation activities are included:

1. **Schema Validation:** Checking whether dataset fields follow the defined data structure.
2. **Missing Value Detection:** Identifying incomplete and missing information.
3. **Duplicate Detection:** Finding duplicate news articles and records.
4. **URL Validation:** Checking the validity and consistency of article URLs.
5. **Domain Validation:** Extracting and checking news source domains.
6. **Data Quality Assessment:** Evaluating completeness and reliability of dataset fields.
7. **Warning Review:** Identifying records that require further inspection.
8. **Quarantine Management:** Separating problematic records for additional review.
