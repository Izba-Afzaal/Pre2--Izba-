# Task 3: Exploratory Data Analysis (EDA)

## Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a news articles dataset to understand its structure, characteristics, distributions, patterns, and overall data quality.

EDA helps explore the dataset through statistical analysis, data profiling, and visualizations to identify useful insights and patterns.

## Objectives

- Understand the structure of the news dataset.
- Perform statistical analysis.
- Analyze missing values.
- Identify duplicate records.
- Explore article categories and domain distributions.
- Analyze article publishing patterns.
- Study title and content length distributions.
- Generate meaningful visualizations.
- Extract useful insights from the dataset.

## EDA Techniques

### 1. Univariate Analysis
Analyzing individual variables, their distributions, and frequency patterns.

### 2. Bivariate Analysis
Exploring relationships between two variables, such as news domains and categories.

### 3. Multivariate Analysis
Examining multiple variables together to identify patterns and relationships.

### 4. Missing Value Analysis
Identifying and analyzing missing values across dataset columns.

### 5. Duplicate Analysis
Examining duplicate records and their distribution.

### 6. Statistical Analysis
Using descriptive statistics to understand numerical data.

### 7. Data Visualization
Creating graphs and charts to communicate patterns and insights.
