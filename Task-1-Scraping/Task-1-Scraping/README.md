
# Task 1 — Web Scraping

## Objective
Collect 100,000 news articles using Python web scraping techniques.

## Project Overview
This task focuses on gathering news articles from multiple news sources and storing the collected data in CSV format for further analysis and preprocessing.

## Data Fields
- Article title
- News source
- Article URL
- Publication date
- Author, where available
- Article text, where available


## Tools and Technologies
- Python
- Requests
- Feedparser
- BeautifulSoup
- Selenium
- Playwright
- Pandas
- RSS feeds and search feeds
- SQLite for local storage (if used in this version)


## Project Files
- 100k_`scraper_target.py` — web scraping code
- `100k_target.csv` — sample of the collected dataset

## Output
A news article dataset prepared for the next stage: data preprocessing and visualization.

## Note
The dataset contains information collected from news sources. Availability of fields may vary by source.
